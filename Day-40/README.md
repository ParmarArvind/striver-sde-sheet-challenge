# Day 40 - Binary Search Trees (Part A)

Solved 3 Binary Search Tree problems covering level connections, searching, and BST construction.

---

## Problems Solved

### 1. Populating Next Right Pointers in Each Node (LeetCode)

**Approach:** BFS (Queue)

**Time Complexity:** O(N)

**Space Complexity:** O(N)

**Idea:** Traverse each level and connect adjacent nodes using a queue.

---

### 2. Search in a Binary Search Tree (LeetCode)

**Approach:** Recursive BST Search

**Time Complexity:** O(H)

**Space Complexity:** O(H)

**Idea:** Use the BST property to recursively search only one subtree.

---

### 3. Convert Sorted Array to Binary Search Tree (LeetCode)

**Approach:** Divide & Conquer

**Time Complexity:** O(N)

**Space Complexity:** O(H)

**Idea:** Pick the middle element as the root to keep the BST height balanced.
